Men LingoSphere – Online Lug'at va Zamonaviy Til O'rganish professional full-stack veb-ilovasini yaratdim!
Ushbu ilova Immersive UI dizayn tizimi asosida yasalgan bo'lib, o'zining chuqur, zamonaviy, to'q fonli (#020617), oynasimon (glassmorphism) elementlari, yorqin gradient ranglari (pink to indigo), nafis animatsiyalari va bento-grid arxitekturasi bilan ajralib turadi.
🎨 Amaliyotda joriy qilingan asosiy imkoniyatlar (Key Features):
So‘z Qidirish (Universal Lookup Pipeline):
Foydalanuvchi inglizcha so'zni yozib qidirganda, tizim ham klassik English Dictionary API'dan ta'riflarni jalb qiladi, ham maxsus Gemini 3.5 Flash modeli orqali o'zbek tilidagi mukammal tushunish materiallarini shakllantiradi.
Kengaytirilgan O‘zbekcha Tarjima va Sharhlar:
So'zning aniq o'zbekcha ekvivalenti, to'g'ri talaffuz qilish sirlari (batafsil sharh), grammatik o'ziga xosliklar, so'z birikmalari qoidalari va so'zni eslab qolish uchun maxsus mnemofrazalar (mnemonic tips) ko'rsatiladi.
Talaffuz Audio (Smart Audio Player):
So'zning haqiqiy audio yozuvlarini eshittiradi. Agar lug'at servisida audio fayl bo'lmasa, brauzerning Web Speech API drayveri yordamida AQSH lahjasida (US Ascent) jonli ovoz chiqariladi.
Tarjimali Misol Gaplar (Interactive Bilingual Examples):
Har bir qidirilgan so'z bo'yicha Gemini AI yordamida 3 ta premium misol gap ingliz tilida tuziladi va o'zbekcha tarjimasi bilan chiroyli kartochkalarga chiqariladi.
Sinonim va Antonimlar (Interlinked Lexical Relations):
So'zga tegishli sinonim va antonimlar alohida burchakda turadi. Ularni bosish orqali darhol yangi so'zni qidirish va leksik bog'liqlikni chuqurroq o'rganish mumkin.
Sevimli So'zlar (Save & Persistent Stars):
Esda qolishi qiyin bo'lgan so'zlarni yulduzcha orqali saqlash mumkin. Ular localStorage orqali saqlanib turadi va statistika sifatida hisoblanib boradi.
Qidiruv Tarixi (Dynamic Search History):
Yaqinda qidirilgan so'zlar ro'yxati vaqtinchalik tarixda saqlanib turadi. Vaqt o'tishi bilan istalgan so'zga qayta bir marta bosish orqali qidiruvni faollashtirish yoki ro'yxatdan o'chirib yuborish mumkin.
Dark / Light Mode:
Kechasi ko'zni charchatmaydigan, premium Immersive UI qorong'u rejimi hamda yorug' rejim mavjud.
Interactive AI Quiz (Til Viktorinasi):
Har bir qidirilgan so'z asosida AI o'zbek foydalanuvchisi uchun 2 ta xorijiy test savoli ishlab chiqadi. To'g'ri/noto'g'ri variantlarni tanlash, javobni tekshirish va AI tomonidan yozilgan to'liq tushuntirishni (explanation) o'qish mumkin.
💻 Texnik Arxitektura & Loyiha Tarkibi:
Frontend: React 19 + TypeScript + Tailwind CSS v4 + Motion (framer-motion) + Lucide React
Backend (API proxy & AI integration): Express.js + Google GenAI SDK (@google/genai) + dotenv
Dizayn uslubi: Immersive UI – shaffof orqa fonlar (glassmorphic), silliq animatsiyalar, .search-glow qidiruv soyasi.
